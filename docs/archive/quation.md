# PROJECT QUOTATION

## Custom Property Reservation & Management Platform

### Project Overview

Development of a custom property/hotel digital platform consisting of:

1. Customer Reservation Web App
2. Public Landing & Content Website
3. Management / Admin Web App
4. MERN backend and database
5. Online payment integration
6. Property, room and booking management
7. Website content management

The system will be developed from scratch as a custom application rather than using WordPress or a pre-built booking template.

---

## 1. Customer Reservation Web App

The reservation application will allow customers to:

- Search available rooms by check-in and check-out dates
- Select number of guests and rooms
- View available rooms
- View room images, amenities, capacity and pricing
- View booking policies
- Select a room
- Enter guest details
- View complete price breakdown
- Complete online payment
- Receive booking confirmation
- View their booking history
- View individual booking details
- Cancel booking according to configured cancellation rules

### Booking System

- Date-based room availability
- Existing booking conflict checking
- Temporary room reservation/hold during payment
- Double-booking prevention
- Booking status management
- Payment status management
- Booking reference generation

---

## 2. Public Landing / Website

A premium responsive property website including:

- Homepage
- Hero/banner section
- Property introduction
- Rooms/stays section
- Amenities
- Gallery
- Offers/promotions
- Experiences/events where applicable

---

## 4. Payment Integration

Online payment will be integrated using the client's payment gateway account.

For Stripe:

- Client's Stripe account will be used
- Payment creation will happen through the backend
- Payment status will be verified server-side
- Stripe webhook integration
- Successful payment → booking confirmation
- Failed payment → booking remains unconfirmed
- Refund handling according to configured booking policy

Payment gateway transaction/processing fees are paid by the client and are not included in the development fee.
